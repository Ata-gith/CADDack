How it works

The reference set is — molecules from ESOL, a standard solubility dataset. Each is stored as a 1024-bit Morgan fingerprint, packed to 128 bytes, which is what makes shipping the whole set to a browser practical. Your query is fingerprinted the same way and compared by Tanimoto: shared bits over total bits.

Similarity has limits worth knowing. Fingerprints count substructures, so they miss shape and conformation, and they saturate on repetitive molecules. Two compounds scoring 0.9 are usually close analogues; two scoring 0.2 are unrelated by this measure but might still bind the same target.

The solubility model is a random forest on the same fingerprints plus six descriptors, held out by Bemis–Murcko scaffold so the test molecules were structurally novel: R² —, mean absolute error — log units. It is trained on drug-like organic molecules, so salts, inorganics and polymers fall outside what it has seen.

Part of CADDack. The same fingerprinting, scaffold splitting and similarity code runs in the Python package under caddack.qsar.
